# 孤独のグルメ マップ

ドラマ『孤独のグルメ』（Season 1〜11・各スペシャル）に登場した実在のお店 **256 店** を地図にまとめたものです。
スマホのブラウザでそのまま開けます。ピンをタップすると、店名・定休日・どのシーズンの何話に出たか・
五郎さんが注文したメニュー・住所が出ます。

## 使い方

- **ピンの色** … シーズンごとの色分け（スペシャルはグレー）
- **斜線入りのグレーのピン** … 閉店したお店
- **絞り込み** … シーズン別／営業状況別の絞り込み、店名・地名・料理名での検索
- **📍** … 現在地を表示。近い順のリストから店に飛べます

## 出典と注意

店舗情報は以下の公開ファンサイトの記載を機械的に集約したものです。

- [予約＆購入ガイド（8888-info.hatenablog.com）](https://8888-info.hatenablog.com/entry/%E3%82%B0%E3%83%AB%E3%83%A1_%E3%83%AD%E3%82%B1%E5%9C%B0%E4%B8%80%E8%A6%A7) — 各シーズンの店舗・住所・営業時間・地図
- [孤独のグルメ情報WEB（kodojo.main.jp）](https://kodojo.main.jp/2021/08/12/alllist/) — 全店舗の営業／閉店状況、Season 11 の各話情報

緯度経度は各記事の Google マップ埋め込みから取得し、住所を
[国土地理院 地名検索API](https://msearch.gsi.go.jp/) でジオコーディングした結果と突き合わせて、
2km 以上ずれているものは住所側の座標に置き換えています。

**定休日・営業時間は変わります。お出かけ前に必ず公式情報でご確認ください。**
「未確認」は出典に記載が見つからなかったものです。
