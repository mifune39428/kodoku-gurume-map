# 孤独のグルメ マップ

ドラマ『孤独のグルメ』（Season 1〜11・各スペシャル）に登場した実在のお店 **256 店** を地図にまとめたものです。
スマホのブラウザでそのまま開けます。ピンをタップすると、店名・定休日・どのシーズンの何話に出たか・
五郎さんが注文したメニュー・住所が出ます。

## 使い方

- **ピンの色** … シーズンごとの色分け（スペシャルはグレー）
- **斜線入りのグレーのピン** … 閉店したお店
- **絞り込み** … シーズン別／営業状況別の絞り込み、店名・地名・料理名での検索
- **📍** … 現在地を表示。近い順のリストから店に飛べます
- **サブタイトルをタップ** … テレビ東京の公式ページのその話に飛びます
- **料理の画像** … その回の一場面が出ます。タップすると公式の動画が開きます

## 出典と注意

店舗情報は以下の公開ファンサイトの記載を機械的に集約したものです。

- [予約＆購入ガイド（8888-info.hatenablog.com）](https://8888-info.hatenablog.com/entry/%E3%82%B0%E3%83%AB%E3%83%A1_%E3%83%AD%E3%82%B1%E5%9C%B0%E4%B8%80%E8%A6%A7) — 各シーズンの店舗・住所・営業時間・地図
- [孤独のグルメ情報WEB（kodojo.main.jp）](https://kodojo.main.jp/2021/08/12/alllist/) — 全店舗の営業／閉店状況、Season 11 の各話情報

緯度経度は各記事の Google マップ埋め込みから取得し、住所を
[国土地理院 地名検索API](https://msearch.gsi.go.jp/) でジオコーディングした結果と突き合わせて、
2km 以上ずれているものは住所側の座標に置き換えています。

**定休日・営業時間は変わります。お出かけ前に必ず公式情報でご確認ください。**
「未確認」は出典に記載が見つからなかったものです。

### 公式ページへのリンク

シーズンごとに URL の付け方が違うため、`tools/build_official.py` で1本ずつ確かめて対応表を作っています。

| シーズン | リンク先 |
|---|---|
| Season 1〜9 | 各話の公式ストーリーページ（108 話ぶん） |
| Season 10 / 11 | 公式サイトが全話を1ページにまとめているため、その一覧ページ |
| 各スペシャル | その特番の公式サイト（14 本） |

Season 4・5・6 は本文が JavaScript で描画され静的に照合できないため、
一覧ページのリンクが 01〜12 の連番であることと、実際にブラウザで開いた
Season 4 第3話・Season 5 第3話の内容が一致することを確認して採用しています。

### 料理の画像について

ドラマのスチル写真そのものはテレビ東京の著作物なので、このサイトには複製していません。
表示しているのは、公式が YouTube で公開しているその回の予告動画のサムネイル画像で、
動画へのリンクを張ったうえで出しています（YouTube の規約で認められている使い方です）。
多くの回は料理のカットがサムネイルになっています。

動画 ID は `tools/build_videos.py` が公式サイトの埋め込みから収集し、64 本すべてについて
YouTube の oEmbed で「テレ東公式 TV TOKYO」「孤独のグルメ / Solitary Gourmet - TV TOKYO」名義の
公開動画であることを確認しています。画像は 1280×720 版を読み、
用意が無い動画（28 本）は YouTube が 120×90 の代替画像を 200 で返してくるので、
読み込み後に幅を見て 320×180 版へ差し替えています。

| 対象 | 画像 |
|---|---|
| Season 7〜11、一部の大晦日SP | あり（256 店中 97 店） |
| Season 1〜6、その他のSP | なし（当時の公式サイトに予告動画が置かれていないため） |

## 構成

```
index.html      地図本体（HTML/CSS/JS 一体）
shops.json      店舗データ
vendor/         Leaflet 1.9.4 + Leaflet.markercluster 1.5.3（CDN 不要）
tools/          shops.json を作り直すためのスクレイピングスクリプト
```

### データを作り直す

`tools/` で以下の順に実行します（出典ページの HTML を同じ階層に置いた状態で）。

```bash
python3 parse_list.py     # 一覧ページ  → shops_raw.json（閉店フラグ）
python3 parse_detail.py   # 各詳細ページ → shops_detail.json（住所・定休日・座標）
python3 parse_status.py   # 全店舗リスト → status_list.json（営業状況）
python3 parse_s11.py      # Season 11   → s11_shops.json
python3 build_data.py     # 座標の検証（国土地理院APIと突き合わせ）
python3 build_official.py # テレ東公式の各話URL → official_map.json
python3 build_videos.py   # 各話の公式予告動画   → video_map.json
python3 final_build.py    # 統合して shops.json を出力
```

Season 11 は出典サイトの更新が追いついていないため、`parse_s11.py` で別途取得しています。
新しいシーズンが始まったら同じ要領で追加してください。
